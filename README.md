# oPongheimer

Pong на двох для Windows: по мережі, за однією клавіатурою або проти бота. Один exe, який достатньо запустити — нічого встановлювати не треба. А в кінці партії на того, хто програв, чекає ядерний гриб.

## Можливості

- **Гра по мережі** — один гравець створює гру, другий підключається за IP.
- **Гра вдвох за одним ПК** — лівий гравець на `W`/`S`, правий на стрілках.
- **Гра проти бота** з трьома рівнями складності.
- **Пауза**, зокрема спільна в мережевій грі.
- **Українська та англійська** мови, перемикаються наживо.
- **Звуки**, синтезовані в пам'яті, — без жодного звукового файлу.
- **Рівні 60 FPS** із синхронізацією з екраном.

## Як грати

Завантажте `oPongheimer.exe` і запустіть. Потрібна 64-бітна Windows 10 або 11; .NET ставити не треба — він уже всередині exe.

### Керування

| Клавіша | Дія |
|---|---|
| `W` / `S` або `↑` / `↓` | рух ракетки |
| `P` | пауза |
| `Space` | реванш після кінця партії |
| `Esc` | вихід у меню |
| `F3` | лічильник плавності |

У режимі «вдвох за одним ПК» клавіші розділені: `W`/`S` — лівий гравець, `↑`/`↓` — правий.

Партія йде до 7 очок. М'яч прискорюється з кожним ударом, а кут відбиття залежить від того, якою частиною ракетки ви влучили.

### Гра по мережі

1. Перший гравець натискає **«Створити гру (хост)»** — у вікні з'являється його IP.
2. Другий вводить цей IP і натискає **«Підключитись»**.

Хост грає лівою ракеткою, клієнт — правою.

Що потрібно, щоб з'єднатись:

- **Одна мережа або VPN.** Для гри через інтернет хосту доведеться пробросити порт на роутері.
- **Порт TCP 7777** має бути дозволений у брандмауері хоста. При першому запуску Windows запитає про це сама.
- **Однакова версія гри** в обох гравців. Якщо версії різні, гра не з'єднається і скаже про це.

## Збірка з коду

Потрібен [.NET 10 SDK](https://dotnet.microsoft.com/download).

Зібрати готовий exe:

```bash
dotnet publish src/Pongheimer.App/Pongheimer.App.csproj -c Release -o publish
```

Результат — `publish/oPongheimer.exe`. Усі налаштування публікації (один файл, вбудований .NET, стиснення) вже записані в проєкті.

Запустити тести:

```bash
dotnet test oPongheimer.slnx
```

## Як усе влаштовано

```
src/
  Pongheimer.Core/     ядро гри, не залежить від графіки
    Game/              правила, фізика, бот, виведення подій зі станів
    Networking/        протокол і TCP-з'єднання
    Sessions/          партії: проти бота, вдвох, хост, клієнт
  Pongheimer.App/      застосунок на MonoGame
    Rendering/         малювання фігур і тексту, поле, вибух
    Ui/                кнопки, перемикачі, поле вводу
    Menu/, Match/      меню та ігровий екран
    Audio/             синтез і відтворення звуків
    Localization/      тексти обома мовами
tests/
  Pongheimer.Core.Tests/   тести ядра
```

Кілька рішень, які варто знати, перш ніж щось міняти:

- **Ядро нічого не знає про екран.** Уся гра — фізика, бот, мережа — живе в `Pongheimer.Core` і покрита тестами. Застосунок лише передає ввід і малює стан, тому графічний шар можна замінити, не чіпаючи правил.
- **Симуляцію веде хост.** Клієнт надсилає позицію своєї ракетки й показує стан від хоста. Власну ракетку клієнт рухає локально, тому керування не відчуває мережевої затримки.
- **Клієнт сам веде м'яч між пакетами.** Пакети хоста й кадри клієнта не збігаються в часі, тож без цього м'яч сіпався б навіть в ідеальній мережі.
- **Мережі не довіряємо.** Кожен вхідний пакет перевіряється; з'єднання починається з обміну версією протоколу.
- **Тексти — це класи, а не файли ресурсів.** Кожна мова — нащадок `Texts`, тож забутий переклад є помилкою компіляції.

Якщо міняєте формат мережевих пакетів, підніміть `Protocol.Version` у `src/Pongheimer.Core/Networking/Protocol.cs`: тоді гравці з різними версіями побачать зрозуміле повідомлення замість дивної поведінки.

## Діагностика

Гра пише журнал і зберігає налаштування тут:

```
%LocalAppData%\oPongheimer\
```

`F3` у грі показує лічильник плавності: частоту кадрів, кількість запізнілих кадрів і час оновлення логіки.

Службові параметри запуску:

| Параметр | Що робить |
|---|---|
| `--perf` | одразу показує лічильник плавності й пише його в журнал |
| `--autostart=bot\|duel\|host\|join` | одразу починає режим, без кліків у меню |
| `--screenshot=2,5.5` | зберігає знімки екрана на вказаних секундах у теку `screenshots` |

## Технології

C#, .NET 10, [MonoGame](https://monogame.net/) 3.8 (DirectX), xUnit.
